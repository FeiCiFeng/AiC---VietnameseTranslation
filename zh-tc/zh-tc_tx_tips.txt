/* ___ tips_punch_0 ___ */
用<key z/>的小攻擊打中魔族時
魔族會噴灑出魔力。
當魔族的魔力越少時越容易昏眩牠們。

/* ___ tips_shotgun_0 ___ */
魔術詠唱中使用<key z/><key lsh/>來保持詠唱，
這時使用小攻撃<key z/>擊中敵人能使出強力的散彈槍。

/* ___ tips_shotgun_1 ___ */
散彈槍的威力以及效果會依據所使用的魔術變化。
使用球型炸彈的情況，有較高的機率昏眩敵人。

/* ___ tips_evade ___ */
迴避<key lsh/>+<key la/><key ra/>能有效減少攻擊以及受傷時的破綻。

/* ___ tips_shield ___ */
在水中以及有毒氣體中展開<key lsh/>護盾，
是可以維持呼吸的。

/* ___ tips_sliding ___ */
使用<key ba/>+<key z/>滑壘碰撞到敵人時會跌倒，
使用時要特別注意。

/* ___ tips_magic_damage ___ */
使用魔術擊中畫面外的敵人時，
傷害量會大幅下降。

/* ___ tips_noon_night ___ */
魔族在早上與晚上出現的規律有所不同。
早上敵人雖少但容易出現強力敵人，
晚上比較容易出現大量較弱的敵人。

/* ___ tips_treasure_0 ___ */
打開寶箱用轉盤時，寶箱內物品的品質及數量，
會根據當時持有的效果轉盤有所變動。

/* ___ tips_treasure_1 ___ */
如果諾艾爾戰敗，所有的寶箱轉盤
會在沒有效果轉盤的加持下全部自動開啟。

/* ___ tips_treasure_2 ___ */
將汙染體打倒後，在掉落清單裡寫著的「？？？」
則代表有機會能獲得敵人的特別素材……？



/* ___ tips_battle_nusi_1 ___ */
用護盾衝擊來反彈催淚彈、燃燒彈、散播花粉
是較為安全的應對方法。


/* ___ tips_nusi_shield_bush_0 ___ */
使用護盾衝擊<key lsh/>+<key z/>能將敵人的投射物反彈。
它就藏在「胞子的舞蹈場」與「溜狗區」之間的某處。

/* ___ tips_grazia_omorashi ___ */
酒吧的店主說不定並不是獸人哦。
如果是魔族的話，大概會對精靈的體液有所反應吧。
在酒吧把那個弄得到處都是的話……？

/* ___ tips_noel_egg ___ */
要取得蛋這個物品，通常必須要在
戰敗之外的情況下產出才行。
據說，商人好像有個可以在安全的情況下
將蛋取出來的器具……的樣子？


/* ___ tips_nightingale_bell ___ */
當身上帶著「商人的鈴」
並在椅子上選擇「等待商人」時，
商人會更積極往諾艾爾這邊過來。

/* ___ bosshint_102_0 ___ */
土龍在地面下亂竄時設下球型炸彈，
並引誘從地底下奔出的土龍吃下炸彈，
吃到炸彈後的土龍會感到畏懼，
在土龍畏懼時就能輕鬆貫穿牠堅硬的鱗片。

/* ___ bosshint_102_1 ___ */
土龍與諾艾爾過遠時，
土龍將會主動鑽到諾艾爾的腳下。

在土龍躍出時，
如果諾艾爾站在與炸彈同位置時，
土龍將會優先吃到炸彈。

有許多會殘留於場上棘手的攻擊，
比如催眠彈和燃燒彈以及尖刺的蘑菇孢子等。

將引爆前的彈幕反彈回去，
讓場上保持乾淨以利戰鬥的進行。

比起到處亂跑各種踩到刺，
或許早點解除狀態更能減少傷害。

可以將魔術維持在詠唱狀態來照亮周圍。

/* ___ tips_fear_buff ___ */
因恐懼而造成最大MP減少時，
魔術放射的攻擊力會增加。
（難易度為休閒時最大兩倍，普通以上最大為1.5倍）

/* ___ tips_fear_cure_by_food ___ */
因恐懼而造成最大MP減少時，
吃過食物後在椅子坐下時能夠稍微舒緩恐懼。
（在這狀態下獲得的恐懼種子也會稍微減少）

/* ___ tips_blackhole_with_fireball ___ */
將能量球與重力球碰撞在一起時，
爆炸的範圍將會變得更廣。

/* ___ tips_watershard_for_lava ___ */
流水碎彈的水彈纏繞於身邊時，
能夠使火炎屬性以及酸液的傷害無效化。

/* ___ tips_flowerycircle_1 ___ */
花環魔術的力場，
能夠防止地面燃燒及結冰。

/* ___ bosshint_210_0 ___ */
當BOSS隱藏身形後，將會使出強力的彈幕攻擊。

或是將設定內「選擇魔術時慢動作」設得慢一些。

以及吊掛在空中的BOSS時，

如果BOSS一直守在高處無法攻擊到時，
試著跳上蜘蛛絲線的平台來接近牠吧。
