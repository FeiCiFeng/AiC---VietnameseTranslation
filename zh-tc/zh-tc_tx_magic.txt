&&Mag_title_whitearrow 純白之箭

/* ___ Mag_desc_whitearrow ___ */
從空中發射的光之箭。
威力較小但是詠唱時間短。
消耗的魔力會在術者的正上方散落，
因此比較容易回收魔力來使用。
在作為支援職在受到襲擊時普及的迎擊手段。


&&Mag_title_fireball 能量球

/* ___ Mag_desc_fireball ___ */
向遠方發射巨大的火球。
可以控制發射後的火球方向三次，
也可以擊中牆壁後面的敵人，
控制方向時術者為無防備狀態，
依據狀況可以用迴避和護盾來中斷控制。
直接命中的威力很大，但是魔力也容易散開來，
觸碰或擊中牆壁時容易誤爆這點要特別注意。

&&Mag_title_dropbomb 球型炸彈

/* ___ Mag_desc_dropbomb ___ */
將能量壓縮成爆彈放置於地面上。
雖然攻擊範圍和威力很弱，但是有讓敵人畏縮的效果，
可以分斷大群敵人，以及爭取魔術的詠唱時間
各式各樣的運用方式，如同名字一樣。
有許多堅固的地形只能使用此魔術破壞，
所以在探索方面有很大的活躍度。

&&Mag_title_thunderbolt 閃電衝擊

/* ___ Mag_desc_thunderbolt ___ */
從空中電力能量向敵人一直線的攻擊。
電力之球在空中停留時需要能量的充能，
在充能結束之前如果碰到敵人或牆壁的話，
能量放出的攻擊力將會下降。
<font color="ff:#FF2B79">這個魔術也會攻擊到自身的關係</font>，
還請盡量小心使用。

&&Mag_title_watershard 流水碎彈

/* ___ Mag_desc_watershard ___ */
召喚8個水彈。
水彈在各自鎖定目標之後便能進行發射。
在漂浮狀態時會像鎧甲那樣圍繞在術者的周圍，
再度詠唱後會進入發射準備模式。




&&Mag_title_powerbomb 高能炸彈

/* ___ Mag_desc_powerbomb ___ */
設置一個會發出強力熱波的爆彈。
除了能破壞特定的地形外，
還能破壞場上所有的手榴彈。
就如其表能對敵人造成不錯的傷害外，
散彈槍的威力也相當地高。

&&Mag_title_flowerycircle 花環


/* ___ Mag_desc_flowerycircle ___ */
在術者周圍展開能使精靈治癒力高漲的力場。
魔族侵入到力場中時會受到攻擊力、防禦力下降的負面效果，
並提升施術者的回復效率。
力場的大小會依據法杖的「鎖定力」有所變化。
對安定體、機械類型的敵人無效。

&&Mag_KD_default (詠唱:&1)

&&Mag_title_blackhole 重力球

/* ___ Mag_desc_blackhole ___ */
在空中產生一個小型重力場。
會將飛行物和輕型敵人吸引至中心，
被抓住的敵人根據其體重受到持續傷害。
（對有一定重量的敵人無效）
力場的大小會依據法杖的「鎖定力」而變化，
力場展開中如再度詠唱能取回一些未使用的魔力。
