&&Smnc_td_rule_title0 概要

/* ___ Smnc_td_rule0 ___ */
為了保護城鎮免於遭受山岳地帶魔族的侵略，
建築防壁並將大軍擊退並殲滅吧。
預計敵人會分三波攻勢進攻。

當敵人突破最後的防壁，
並到達地圖最左邊之時，
將會強制敗北。


&&Smnc_td_rule_title1 配置的基礎
/* ___ Smnc_td_rule1 ___ */
首先，盡可能地放置多個防壁。
但防壁並不是能無限制建造的，
必須要控制在軍隊所給予的預算範圍內。

如果牆與牆之間的間隔過於狹窄，
在進行人員配置時候，
每個牆後能配置的人數將會減少。
建設時互相保持三～四格之間是最基本的。


&&Smnc_td_rule_title2 掩護射擊.1

/* ___ Smnc_td_rule2 ___ */
媞古莉娜將會在宿舍屋頂上的砲台
進行掩護射擊來參與戰鬥。

此外，砲台能裝填的砲彈並不是無限的，
這些也必須控制在預算範圍內。
將建築所剩的資金投注在這也是挺好的。


&&Smnc_td_rule_title3  援護射撃.2

/* ___ Smnc_td_rule3 ___ */
媞古莉娜將會依據戰況
從四種砲彈中選出最合適的來發射。

部分砲彈也會擊中諾艾爾及其同伴
所以諾艾爾過於在牆外行動時，
將會使得媞古莉娜難以發射砲彈。



&&Smnc_td_rule_title4 人員配置
/* ___ Smnc_td_rule4 ___ */
用「人員配置」在場地上面配置我方，
並能與我方一同參加防衛作戰。(最多&1人)

依據人員所配置的位置，
他們將會自動從步兵、救護兵、砲兵
中被分配一個職務。

&&Smnc_td_rule_title5 步兵.1
/* ___ Smnc_td_rule5 ___ */
配置在防壁附近，或是瞭望塔上面的人員，
將作為步兵。

步兵為了保護防壁，
會使用純白之箭和能量球來迎戰魔族。
(瞭望塔上面的人員優先使用能量球)


&&Smnc_td_rule_title6 步兵.2
/* ___ Smnc_td_rule6 ___ */

防壁遭到破壞後，
步兵將會自動從戰線退至後方的防壁，
繼續進行攻勢。

魔力不足時將會無法戰鬥，
因此在牆內側建立一個魔力塔，
防衛會較為穩定。

&&Smnc_td_rule_title7 砲兵
/* ___ Smnc_td_rule7 ___ */
將人員配置於宿舍屋頂，媞古莉娜附近時，
人員將會作為砲兵。

砲兵不會直接出現在場地上，
會依據所配置的人員多寡
媞古莉娜大砲的發射速度將會上昇。
(人數配置過多時，增加的上昇幅度將會減少)

&&Smnc_td_rule_title8 救護兵
/* ___ Smnc_td_rule8 ___ */
配置在急救帳篷附近人員將作為救護兵，
並會新增紫色的圖標。
救護兵會趕到倒地的同伴那裡，
將同伴運回急救帳篷。

為了能更方便使用擔架，
兩人一組的人員配置是最基本的。

&&Smnc_td_rule_title9 急救帳篷
/* ___ Smnc_td_rule9 ___ */
被運到急救帳篷的同伴，
經過一段時間的恢復後就會再度回歸戰線。

有建設急救帳篷時普莉姆拉將會出現。
當普莉姆拉在帳篷實施治療時，
