/* ___ Enemy_description_SLIME ___ */
非常原始的魔族。
智能低卻意外有著強力的跳躍力。
成群結隊而來時要注意別被吸取魔力了。

/* ___ Enemy_description_SLIME_OD ___ */
吸入過多魔力，變得更加喪失理智
會將精靈生吞後照著本能鑽入卵管內，
千萬別被牠抓到了。

/* ___ Enemy_description_GOLEM ___ */
主要棲息於廢坑道群居地的魔族。
運用著各式各樣的組裝技術來玩弄精靈於股掌。
當牠們開始著手組裝時，在組裝完成前除掉牠們吧。

/* ___ Enemy_description_GOLEM_OD ___ */
體型變得巨大，投石攻擊變為巨大的棍棒。
儘管外表粗魯，但似乎有驚人的智力。
跨到牠後面來迴避掉二連擊後進行攻擊比較好。



/* ___ Enemy_description_MUSH ___ */
棲息於潮濕地方的魔族。
會射出胞子團進行攻擊。
當牠躲進地面時攻擊會不太管用，
用散彈槍來將牠拉出來吧。


/* ___ Enemy_description_MUSH_OD ___ */
彷彿為了消散原先不能動的鬱悶
而變得驚人地俊敏。
大量放出的瓦斯裡有著
會使人受到「種子寄生」的異常狀態效果。
當牠欠缺瓦斯並重新裝填胞子時
會出現破綻，在那時攻擊牠吧。

/* ___ Enemy_description_PUPPY ___ */
身上纏著許多蟲子行動靈敏的魔族。
動作迅速至用純白之箭也難以跟上牠。
當牠身上纏繞著蟲子時受到的HP傷害都會由MP來承受。
使用能量球直擊牠時爆炸以及爆風
對牠造成兩段傷害較為輕鬆。

/* ___ Enemy_description_SPONGE ___ */
會將多餘魔力儲存於枝幹黑球裡的魔族。
牠會向其他魔族發射魔力彈，
使用魔力來對其進行回復。
太過靠近牠使牠會躁動起來
當牠安靜下來後使用散彈槍來打牠是好選擇。

/* ___ Enemy_description_UNI ___ */
全身布滿刺的魔族。
牠會隨心所欲地飄浮於空中，
偶而會突然將刺集中於前方進行突擊。
因沒有特別弱點存在，
盡早使用魔術來打倒牠吧。


/* ___ Enemy_description_UNI_OD ___ */
汙染體化後變得沉重的魔族，
只能藉由尖刺在地面以及牆壁滾動
當牠發出巨大的吼叫時
要注意牠使用的廣範圍突刺。

/* ___ Enemy_description_SNAKE ___ */
會潛入於地下裡，
並從對手腳下跳出來使出拘束的魔族。
如果在牠跳出來地方放置球型炸彈，
使之吃下後能對牠造成昏眩。


/* ___ Enemy_description_GECKO ___ */
能用四隻腳在牆壁上移動的魔族。
使用一發攻擊來擊中後
牠會摔個倒栽葱露出破綻。
在牠撲過來時給予牠輕擊。

/* ___ Enemy_description_MAGE ___ */
模仿學習了第一世代魔術「閃電衝擊」
並只會在夜晚出現的魔族。
當被魔術鎖定時會使用瞬間移動來進行迴避。
別被牠的行動給迷惑了
先行預測對手的行動來進行佯攻吧。

/* ___ Enemy_description_FOX ___ */
看守著森林特定區域的稀少魔族。
散落在地上的火焰會持續一段時間，
所以盡可能的在高處戰鬥。
有著非常強的戰鬥力但是魔力消耗也非常大
牠會頻繁往有魔力植物的地方移動。


/* ___ Enemy_description_FROG ___ */
看守著沼澤的稀少魔族。
會對我方的反應並做出跳躍發射凍結彈。
先躲遠一點詠唱，
等待牠跳躍後在找機會反擊吧。




/* ___ Enemy_description_BOSS_NUSI ___ */
棲息在森林裡的大型魔族。
被里的精靈軍打倒了……事情被當成這樣了。

/* ___ Enemy_description_PIG ___ */
棲息在山裡的魔族。
體型龐大但動作卻很敏捷，
特別是牠有著能用巨大的牙
把周遭的的敵人通通打飛的蠻力在。
如果用近距離攻擊打中牠，牠會使出反撲倒
用遠距離戰鬥較為理想。



/* ___ Enemy_description_PENTAPOD ___ */
棲息於山中的魔族。
會從上面的頭部發射出光束。
被光束擊中有可能會石化，
遭連續擊中的話身體會動彈不得非常的危險。
底部雖然很結實但是稍有一點攻擊就會使之畏懼，
使用炸彈來嚇唬牠後並朝頭部使出強力攻擊吧。



/* ___ Enemy_description_ROAPER ___ */
棲息於山中的魔族。
會從細長的身體裡延伸出觸手，
並纏縛在精靈身上來吸取魔力。
當牠發出吼叫時，就是要呼叫大量觸手
來使出強力拘束技的預兆。
在牠吼叫時給予傷害的話，
能對牠造成會心一擊。
