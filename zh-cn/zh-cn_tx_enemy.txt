/* ___ Enemy_description_SLIME ___ */
原始的魔族。
虽然智力低下，但跳跃力意外地强。
会成群结队地来袭，小心别被吸干了魔力。

/* ___ Enemy_description_SLIME_OD ___ */
不仅吸取了大量魔力，还完全没有理智可言。
一旦被它吞入体内，就会被它本能地使用输卵管进行侵犯。
因此千万要注意别被它被抓住。

/* ___ Enemy_description_GOLEM ___ */
主要栖息在废弃矿道中的群居性魔族。
使用各种工艺技术制造装置，将精灵玩弄于股掌之中。
如果它们开始组装什么东西，请务必在完成之前将其解决掉。

/* ___ Enemy_description_GOLEM_OD ___ */
体型更为巨大，且手里的投石器也换成了巨大的棍棒肆意挥舞。
初见便能感到此敌人四肢发达，但实际上其头脑也并不简单。
最好高高跳起躲开它们的二连击，再绕到它们的背后进行反击。



/* ___ Enemy_description_MUSH ___ */
栖息于潮湿环境的魔族。
通过发射出充满孢子的囊孢进行攻击。
由于它缩进地面时很难对其造成伤害，
因此可以用魔法霰弹将其逼出。


/* ___ Enemy_description_MUSH_OD ___ */
或许是想发泄曾经无法移动的怨气，如今拥有了惊人的机动性。
会散布大量孢子气体，给吸入的宿主附加「植物寄生」状态。
不过当孢子气体耗尽后，孢子的重新填充速度会明显减慢，
这个破绽正是打倒敌人的好机会。

/* ___ Enemy_description_PUPPY ___ */
身上缠绕着大量蠕虫型幼体，四处奔跑的魔族。
动作迅速，因此很难用纯白之箭直接命中。
身上有幼体缠绕时，受到的HP伤害会用MP来抵消。
因此用聚能火球直接攻击，或利用爆炸将其击飞会更好。

/* ___ Enemy_description_SPONGE ___ */
在枝杈末梢的黑色球体中储存大量魔力的魔族。
会向其他魔族发射魔力弹，为其他魔族提供魔力补给。
有人靠近时会狂乱地攻击四周，
算好其沉静下来的时机再用魔法霰弹进行攻击即可。

/* ___ Enemy_description_UNI ___ */
全身覆盖着尖刺的魔族。
有时前一秒还在空中漂浮不定，
下一秒就会突然集中尖刺猛冲过来。
没有明显的弱点，因此务必设法尽早击败它。


/* ___ Enemy_description_UNI_OD ___ */
变为污染体后身体十分沉重无法再漂浮，
因此只能将刺扎入地面和墙壁支撑自身滚动。
发出巨大吼声时会进行大范围的刺击，需格外小心。

/* ___ Enemy_description_SNAKE ___ */
游走在地面之下，在潜伏中
突然钻出并束缚住猎物的魔族。
如果在它即将钻出的位置提前放置地面炸弹，
它便会误食炸弹并被炸晕。


/* ___ Enemy_description_GECKO ___ */
能以四足吸附在墙面上奔跑的魔族。
只要受到攻击便会翻倒，从而露出破绽。
当它飞扑过来的时候，轻轻击打即可应对。

/* ___ Enemy_description_MAGE ___ */
学习并复现了第一世代魔法「雷霆电击」，
只会在夜晚出现的特殊魔族。
被魔法锁定时，会尝试通过传送等方式进行躲避。
不要被它的动作所迷惑，将计就计地
用假动作来预判对方的行动吧。

/* ___ Enemy_description_FOX ___ */
在森林中划地为王的稀有魔族。
其撒在地面的火焰会持续燃烧一段时间，
因此最好在高处作战。
虽然拥有强大的歼灭能力，但魔力的消耗量也很大，
因此它总是会朝有魔力植物的地方移动。


/* ___ Enemy_description_FROG ___ */
以沼泽为领地的稀有魔族。
一旦它判断你有攻击意图，
便会飞扑过来并射出冰冻弹。
可以对着它背后进行咏唱，等待它先跳跃后，
再抓住时机进行反击。




/* ___ Enemy_description_BOSS_NUSI ___ */
栖息于森林的大型魔族。
已经被村里的精灵军队消灭了……至少表面上是这样。

/* ___ Enemy_description_PIG ___ */
栖息在山中的魔族。
不仅身形庞大，而且行动灵敏。
要特别注意那硕大的白色獠牙，
其力量足以将周围的敌人击飞。
如果使用近战攻击反而会遭到扑身压制，
因此最好使用以远程攻击为主的战斗方式。



/* ___ Enemy_description_PENTAPOD ___ */
栖息在山中的魔族。
其高悬在上方的头部会发射特殊的光束，
被光束击中后可能会附加石化效果，
如果多次被击中则会完全失去行动能力，十分危险。
其下盘非常坚固，但受到些许攻击便会畏怯，
用炸弹或其它攻击使之畏怯后再瞄准头部进行强力攻击吧。



/* ___ Enemy_description_ROAPER ___ */
栖息在山中的魔族。
细长的身体中伸出的无数触手，
每根都能够缠绕在精灵身上吸取魔力。
当它发出咆哮时，一定要当心接下来
它用大量触手发动的猛烈束缚攻击。
看准时机，在它咆哮的时候
发起会心一击，或许会有奇效。
