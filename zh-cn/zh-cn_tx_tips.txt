/* ___ tips_punch_0 ___ */
按下<key z/>对魔族进行轻攻击时，
不仅会使其逸散出少量的魔力，
还能让魔力较少的魔族陷入眩晕状态。

/* ___ tips_shotgun_0 ___ */
在咏唱魔法时按下<key z/>或<key lsh/>
再对敌人使用轻攻击<key z/>，就能使出强大的魔法霰弹。

/* ___ tips_shotgun_1 ___ */
魔法霰弹的威力和效果取决于咏唱的魔法种类。
咏唱地面炸弹使出的魔法霰弹更容易击晕敌人。

/* ___ tips_evade ___ */
按下<key lsh/>+<key la/><key ra/>闪避可以中断攻击或受击时的读秒，从而减少破绽。

/* ___ tips_shield ___ */
使用<key lsh/>展开护盾，
便可暂时在水下或有毒气体中呼吸自如。

/* ___ tips_sliding ___ */
可以按下<key ba/>+<key z/>进行滑铲。
不过要注意，滑铲撞上敌人会摔倒哦。

/* ___ tips_magic_damage ___ */
如果尝试用魔法攻击视野外的敌人，
造成的伤害将会大幅下降。

/* ___ tips_noon_night ___ */
在一天的不同时段，魔族的生成规律也有所不同。
整体而言白天的敌人量少而难缠，夜晚的敌人更弱但数量众多。

/* ___ tips_treasure_0 ___ */
开启转轮宝箱时，其内容物的数量和品质
会根据此时拥有的效果转轮而发生变化。

/* ___ tips_treasure_1 ___ */
当诺艾儿败北无法继续战斗时，身上所有的转轮宝箱
会在失去效果转轮的状态下自动打开。

/* ___ tips_treasure_2 ___ */
在掉落物中显示有「？？？」的地点打倒污染体后，
或许能得到包含特殊素材的转轮宝箱……？



/* ___ tips_battle_nusi_1 ___ */
面对森之领主发射的催泪弹、燃烧弹以及挥洒出的棉毛等等，
直接用护盾冲击弹回去是最佳选择。


/* ___ tips_nusi_shield_bush_0 ___ */
使用<key lsh/>+<key z/>能发动护盾冲击把飞来的投掷物弹开。
这个技能藏在「孢子舞台」和「遛狗公园」之间的某处，
如果你还没获得这个技能，不妨去找找吧。

/* ___ tips_grazia_omorashi ___ */
酒吧的店主看起来并不像兽人。
魔族应该会对精灵的体液起反应，
所以如果把体液洒在酒吧里的话……？

/* ___ tips_noel_egg ___ */
要获得自己的卵……
等到败北之时才把它排出来可就晚了。
听说商人有道具能把卵安全地取出来，
不知道是真是假……？


/* ___ tips_nightingale_bell ___ */
拿着「商人的铃铛」的时候，
坐在长椅上并且选择「等待商人」，
商人就会很快赶来了。

/* ___ tips_granade_0 ___ */
当心！带着超过4个手榴弹时

// 领主
/* ___ bosshint_104_0 ___ */
森之领主会在场地上四处释放烟雾弹、
发射燃烧弹、投掷带刺孢子等，
将周遭弄得乱七八糟，相当难缠。

活用<font color="ff:#ffff33">护盾冲击</font>之类的具有范围伤害的技能
就可以在那些投射物起爆之前将其击毁，
甚至弹飞回去。
保持场地整洁，也有利于提升作战效率。



/* ___ bosshint_104_1 ___ */
身上着火的时候可以使用
圣光爆发<key PR_BURST/>扑灭身上的火焰。
虽说连续使用会提升晕厥的概率，
但着火除了火焰伤害外，四处乱跑踩到荆棘的概率也不小，
综合来看还是早点扑灭身上的火比较好。

/* ___ tips_overcharger ___ */
使用过充插槽，可以在战斗期间将无法稳定维持的魔力
储存起来备用，每个插槽储存的魔力足以释放一次魔法。

便可以照亮周围的环境。

/* ___ tips_magic_absorb_map_end ___ */

/* ___ bosshint_209_0 ___ */
被一大群小型敌人团团围住的话，
就使用<font color="ff:#ffff33">引力黑洞<key BLACKHOLE/></font>把它们一扫而空吧。

/* ___ tips_fear_buff ___ */
恐惧效果在导致MP上限降低的同时，
也会在一定程度上提升远程魔法的攻击力。
（在休闲难度下最高提升至2倍，其他难度则为1.5倍）

/* ___ tips_fear_cure_by_food ___ */
如果因为恐惧效果导致MP上限降低，
吃点东西再坐上长椅，就能些许地缓解恐惧了。
（通过此方法安抚恐惧时，获得的恐惧之种较少。）

/* ___ tips_blackhole_with_fireball ___ */
发射到引力黑洞里面的聚能火球
爆炸有效范围会变得更大哦。

/* ___ tips_watershard_for_lava ___ */
环链水阵产生的水球可以抵御火焰属性
以及酸液造成的伤害。

/* ___ tips_flowerycircle_1 ___ */
疗愈花环的力场范围内，
地面不会着火或结冰。


// 蜘蛛用ヒント

/* ___ bosshint_210_0 ___ */
蜘蛛习惯在隐遁身形后立即发动猛烈的弹幕攻击。
这时请果断使用引力黑洞<key BLACKHOLE/>魔法
将四面八方飞射的弹丸悉数解决掉吧。
如果觉得按2次方向键才能使出这个魔法过于繁琐，
不妨将它放在更便于操作的魔法键位上，
或是在设置中将「选择魔法时的慢镜头」调得更慢吧。

/* ___ bosshint_210_1 ___ */
在引力黑洞<key BLACKHOLE/>的生效范围内，
蜘蛛施放的所有投掷物（光束除外）都会被吸收掉。
请牢记这个特性，灵活使用这一技能吧。


/* ___ bosshint_210_2 ___ */
当蜘蛛在墙壁上攀爬或悬吊在天花板上时，
如果使用魔法霰弹命中它，便有可能让它
失去平衡、坠落下来。
如果蜘蛛盘踞在高处、无法通过跳跃直接够到，
也可以踩着蜘蛛丝形成的落脚点逐步向它靠近。

当此类项目被放置在快捷使用面板中央时，
短按<key s/>即可快速生效。
