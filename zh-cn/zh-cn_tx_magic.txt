&&Mag_title_whitearrow 纯白之箭

/* ___ Mag_desc_whitearrow ___ */
从空中发射光箭。
威力较小但咏唱时间较短，
消耗的魔力会在施法者的正上方散落，
因此比较容易回收魔力且较易使用。
作为支援职业受到袭击时的牵制手段被广泛普及。


&&Mag_title_fireball 聚能火球

/* ___ Mag_desc_fireball ___ */
向远处发射巨大的火球。
发射后的火球可以进行最多3次的方向操控，
因此可以用于攻击隔着墙壁的目标，
但由于在操控方向时施法者是毫无防备的状态，
故需要根据情况选择使用闪避或护盾以中断操控。
虽然直接击中敌人时威力很大，但要注意魔力容易飞散
以及与墙壁之类的东西接触时，容易被误引爆。

&&Mag_title_dropbomb 地面炸弹

/* ___ Mag_desc_dropbomb ___ */
将能量压缩成炸弹，向地面发射。
攻击范围和威力有限，但具有震慑敌人的效果，
因此如果在一大群敌人中间想为咏唱魔法争取时间的话，
就巧妙地利用这个魔法来争取宝贵的作战时机吧。
另外，不少薄而坚固的地形得用这个魔法才能破坏，
所以在探索地图时可不能忘了它。

&&Mag_title_thunderbolt 雷霆电击

/* ___ Mag_desc_thunderbolt ___ */
从空中以直线状发射雷电能量攻击敌人。
需要预先在空中积蓄能量维持雷电能量球，
因此如果在蓄力完成之前，能量球撞到墙壁或敌人的话，
会导致能量向周围扩散、威力大幅减小。
<font color="ff:#FF2B79">这个魔法对自己也有攻击判定，</font>
所以必须要十分小心地使用。

/* ___ Mag_desc_pr_burst ___ */
同时长按<key PR_BURST/>发动。
使用引爆的魔力猛击，从而将周围的敌人震开。
只要施法者意识清醒就可以发动。
但是飞散的绝大部分魔力施法者无法回收，
有可能会给对手白白送上魔力。
此外,在没有魔力的状态下使用爆发魔法的话，
会对施法者的精神造成极大的损伤。

&&Mag_title_watershard 环链水阵

/* ___ Mag_desc_watershard ___ */
召唤8团水球。
可以将各个水球锁定不同的目标
发射出去，也可以使其保持漂浮状态，
如护盾一般环绕在施法者身边，
此时再次咏唱该魔法可进入瞄准锁定状态。




&&Mag_title_powerbomb 高能炸弹

/* ___ Mag_desc_powerbomb ___ */
能够释放出强力热浪的炸弹。
布设后可摧毁特定地形，还能清除
范围内的所有实体（如榴弹等）。
爆炸效果猛烈，但直接杀伤的效率一般，
以魔法霰弹的形式才能发挥最大的威力。

&&Mag_title_flowerycircle 疗愈花环


/* ___ Mag_desc_flowerycircle ___ */
在施法者身边生成魔法力场，提升范围内精灵的恢复能力，
若有魔族踏入力场，则其攻击力和防御力将会降低，
力场则会在吸取魔族力量后，进一步提升增强恢复力的效果。
力场的大小取决于法杖的「锁定性能」高低，
但对稳态附加属性或机械类的敌人无法生效。

&&Mag_KD_default (咏唱:&1)

&&Mag_title_blackhole 引力黑洞

/* ___ Mag_desc_blackhole ___ */
在空中生成小型引力场。
引力场能够吸引投射物及重量较轻的敌人，
被吸到中心的敌人将会根据自身体重
持续受到伤害。
（对体重大于一定重量的敌人无效）
引力场的大小取决于法杖的「锁定性能」高低。
引力场展开时再次咏唱可消除引力场，并回收未使用的魔力。
