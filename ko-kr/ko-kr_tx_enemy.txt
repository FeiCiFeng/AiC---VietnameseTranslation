/* ___ Enemy_description_SLIME ___ */
원시적인 마족.
지능은 낮지만 의외로 도약력이 있다.
무리에게 습격당해 마력을 드레인당하지 않도록 주의.

/* ___ Enemy_description_SLIME_OD ___ */
대량의 마력을 빨아들였으며 이성을 잃었다.
엘프를 삼켜 본능에 맡긴 채 산란관을 쑤셔넣기 때문에
절대 잡히지 말 것.

/* ___ Enemy_description_GOLEM ___ */
주로 폐광에 무리지어 서식하는 마족.
다양한 공작기술로 엘프를 농락한다.
그들이 무언가를 만들기 시작했다면 완성되기 전에 배제할것.

/* ___ Enemy_description_GOLEM_OD ___ */
거대해져 투석기를 거대한 곤봉으로 사용한다.
난폭한 생김새에 반해 지능은 의외로 높은 듯 하다.
2연격을 점프 등으로 피해 배후에서 공격하는 것이 좋다.



/* ___ Enemy_description_MUSH ___ */
습한 곳에 서식하는 마족.
포자탄을 발사해 공격한다.
지면에 숨어있을 때에는 공격이 잘 통하지 않지만
샷건으로 끄집어낼 수 있다.


/* ___ Enemy_description_MUSH_OD ___ */
원래는 움직이지 못하던 울분을 풀고 싶은 것인지 놀랄 정도로 기민하다.
대량의 가스를 살포해 상대를 '기생목' 상태로 만든다.
다만, 한 번 가스를 살포한 후에는 포자의 재장전이
눈에 띄게 둔해지기 때문에 그 때를 노리자.

/* ___ Enemy_description_PUPPY ___ */
다수의 벌레의 유체를 몸에 두른 채 달리는 마족.
움직임이 빨라 화이트 애로우를 명중시키기 어렵다.
유체를 두르고있을 때에는 HP의 대미지를 MP로 치환한다.
에너지 볼을 직격시켜 폭발로 날려버리는 것이 낙.

/* ___ Enemy_description_SPONGE ___ */
마디에서 자라난 검은 구체에 대량의 마력을 비축하는 마족.
다른 마족에게 마력탄을 쏘아 마력을 회복시킨다.
다가가면 날뛰지만 잠잠해진 후에는 샷건으로 처리하기 쉽다.

/* ___ Enemy_description_UNI ___ */
전신에 가시를 두른 마족.
둥실둥실 떠다닌다 싶다가도
갑작스럽게 가시를 전방에 집중시켜 달려들기도.
이렇다 할 약점이 없기 때문에 마술로 빠르게 처리하자.


/* ___ Enemy_description_UNI_OD ___ */
오염체화되어 무거워졌으며 지면이나 벽에 가시를 꽂아
굴려다닐 수밖에 없어졌다.
큰 울음소리를 낸 후의 광범위한 찌르기에 주의.

/* ___ Enemy_description_SNAKE ___ */
지면에 숨어 상대의 발밑에서 튀어올라 구속하는 마족.
튀어오르는 곳에 그라운드 봄을 놓아두면
그것을 삼키고 기절한다.


/* ___ Enemy_description_GECKO ___ */
벽을 네 발로 기어다니는 마족.
공격을 한 번 명중시키면 뒤집어져 빈틈을 보인다.
착지하는 곳을 노리자.

/* ___ Enemy_description_MAGE ___ */
제1시대마술 '썬더 볼트'의 레플리카를 학습한
특수한 밤에만 출현하는 마족.
마술로 록온하면 워프 등을 활용해 회피한다.
움직임에 현혹되지 않도록 이쪽도 페인트를 활용해
상대의 움직임을 읽어내자.

/* ___ Enemy_description_FOX ___ */
숲의 특정 장소를 영역으로 삼는 희소마족.
지면에 흩뿌려진 화염은 잠시 잔류하기 때문에
되도록이면 고지대에서 싸울 것.
살상력이 높은 만큼 연비가 나빠
항상 마력식물로 향하는 습성을 가진다.


/* ___ Enemy_description_FROG ___ */
늪을 영역으로 삼는 희소마족.
상대의 공격의사를 간파해 뛰어올라
빙결탄을 쏘아 공격한다.
뒤를 보고 영창해 먼저 상대가 뛰어오르기를
기다려 카운터를 먹여주자.




/* ___ Enemy_description_BOSS_NUSI ___ */
숲에 서식하는 대형마족.
마을의 엘프 군대가 쓰러트렸다……는 것으로 되어있다.

/* ___ Enemy_description_PIG ___ */
산에 서식하는 마족.
거대하면서도 움직임은 기민하며
특히 거대하고 흰 엄니는
주위의 적을 날려버릴 정도의 힘을 지닌다.
근접공격에는 카운터로 누르기 공격을 하기 때문에
원거리 공격 위주로 싸우는 것이 바람직하다.



/* ___ Enemy_description_PENTAPOD ___ */
산에 서식하는 마족.
상부의 잘 닦인 두부에서 빔을 발사한다.
빔에 맞으면 석화되며 연속으로 당할 경우
움직일 수 없어져 상당히 위험하다.
근본적으로 단단하지만 일단 공격당하면 정지하기 때문에
봄 등으로 멈추게 한 후 두부에 강한 공격을 꽂아넣자.



/* ___ Enemy_description_ROAPER ___ */
산에 서식하는 마족.
가늘고 긴 몸에서 여러개의 촉수를 뻗어
엘프에게 달라붙어 마력을 흡수한다.
포효는 더욱 많은 촉수를 사용해
강력한 구속을 시도하는 신호.
포효중에 피해를 입으면 더욱 큰 피해를 입는다.
