/* ___ Enemy_description_SLIME ___ */
原始的な魔族。
知能は低いが意外と跳躍力がある。
群れを為して襲われて魔力をドレインされないよう注意。

/* ___ Enemy_description_SLIME_OD ___ */
多くの魔力を吸い、さらに正気を失っている。
エルフを丸呑みすると本能のままに卵管を差し込んでくるため、
決して捕まらないように。

/* ___ Enemy_description_GOLEM ___ */
主に廃坑道にコロニーを形成して生息する魔族。
様々な工作技術によってエルフを翻弄する。
彼らが何かを組み上げ始めたら、作業が終わる前に排除するべき。

/* ___ Enemy_description_GOLEM_OD ___ */
巨体になり投石機を巨大な棍棒に持ち替えた。
粗暴な出で立ちだが意外なほどに知能は高いようだ。
二連撃を飛び越えるなどして避け、背後から攻撃するのが良い。



/* ___ Enemy_description_MUSH ___ */
じめじめした場所に生息する魔族。
胞子団子を射出して攻撃する。
地面に隠れているときは攻撃が通りにくいが、
ショットガンで引っ張り出せる。


/* ___ Enemy_description_MUSH_OD ___ */
元々動けなかった鬱憤を晴らしたいのか、驚くほどに俊敏。
大量の胞子ガスをばらまいて「宿り木」の状態異常を付与してくる。
ただし、一度ガス欠になった後は胞子の再装填が
目に見えて鈍くなるため、そこを叩こう。

/* ___ Enemy_description_PUPPY ___ */
多数のワーム型の幼体を身にまとって走り回る魔族。
動きが早いので、ホワイトアローでは捉えにくい。
幼体をまとっている間はHPダメージをMPで肩代わりする。
エナジーボールを直撃させ、爆風で吹き飛ばすのが楽。

/* ___ Enemy_description_SPONGE ___ */
節から生えた黒球に多くの魔力を蓄えられる魔族。
他の魔族に向かって魔力弾を放ち、魔力の回復を図ってくる。
近づくと暴れ出すが、大人しくなった頃を見計らって
ショットガンを当てるのが良い。

/* ___ Enemy_description_UNI ___ */
全身をトゲで覆った魔族。
ふらふらと宙を飛んでいるかと思いきや、
突然トゲを一方向に集中させ突撃してくることも。
これといった弱点はないので、早めに魔術を集中的に当てて倒そう。


/* ___ Enemy_description_UNI_OD ___ */
汚染体化したことで重くなり、地面や壁にトゲを突き立てて
転がることしかできなくなった。
大きな鳴き声を上げたときに行う広範囲の突き刺しに注意。

/* ___ Enemy_description_SNAKE ___ */
地面に潜り、相手の足元から飛び出して
拘束をしかける魔族。
飛び出す場所にグラウンドボムが置かれていると、
それを食べてスタンする。


/* ___ Enemy_description_GECKO ___ */
壁を四足で走り回る魔族。
攻撃を一発当てるとひっくり返って隙を見せる。
飛びかかってきた所を軽くこずいてあげよう。

/* ___ Enemy_description_MAGE ___ */
第一世代魔術「サンダーボルト」のレプリカを
学習した夜にのみ出現する、特殊な魔族。
魔術でロックオンするとワープなどの回避行動を取る。
動きに惑わされぬよう、こちらもフェイントを入れて
相手の動きの先を読もう。

/* ___ Enemy_description_FOX ___ */
森の特定位置を縄張りとする希少魔族。
地面に撒き散らされた火炎はしばらく残るので、
なるべく高所で戦うべき。
殲滅能力が高い分燃費は悪く、常に魔力植物のある
場所に向かって移動する習性を持つ。


/* ___ Enemy_description_FROG ___ */
沼を縄張りとする希少魔族。
こちらが攻撃意思を見せたと判断すると、
飛びかかって凍結弾を打ってくる。
背を向けて詠唱し、先に相手が
ジャンプするのを待ってからカウンターを食らわせよう。




/* ___ Enemy_description_BOSS_NUSI ___ */
森に生息する大型魔族。
里のエルフ軍が倒した……ことになっている。

/* ___ Enemy_description_PIG ___ */
山に生息する魔族。
巨体ながら動きは俊敏であり、特に
巨大な白いキバは周りの敵を吹き飛ばすほどの
パワーを持っている。
近接攻撃を当てるとカウンターの押し潰し攻撃を
行うため、遠距離攻撃主体で戦うことが望ましい。



/* ___ Enemy_description_PENTAPOD ___ */
山に生息する魔族。
上部に吹き上げている頭部からビームを発射する。
ビームに当たると石化してしまうことがあり、
連続で食らうと身動きが取れなくなり大変危険である。
根本は固いが僅かでも攻撃を当てれば怯むため、
ボムなどで怯ませた後頭部に強い攻撃を叩き込もう。



/* ___ Enemy_description_ROAPER ___ */
山に生息する魔族。
ひょろ長い身体からいくつもの触手を伸ばし、
エルフに取り付いて魔力を吸収する。
雄叫びを上げた時は、さらに大量の触手を使って
強力な拘束をしてくる合図。
雄叫びの最中にダメージを与えると
クリティカルヒットとなる。
