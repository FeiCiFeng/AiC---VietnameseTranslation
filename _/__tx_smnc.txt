&&Smnc_td_rule_title0 概要

/* ___ Smnc_td_rule0 ___ */
山岳方面から攻めてくる魔族から街を護るため、
防壁を建築し大軍勢を殲滅、撃退しましょう。
敵は3ウェーブに分けて押し寄せて来ると予想されます。

敵がマップ左端まで到達し、
最後の防壁を突破されると強制的に敗北となります。


&&Smnc_td_rule_title1 基本の配置
/* ___ Smnc_td_rule1 ___ */
まずは、なるべく多く防壁を配置しましょう。
防壁は無限に建てられる訳ではなく、
軍から支給された予算内に収める必要があります。

このとき壁どうしの間隔が狭すぎると、後述の
人員配置の際に壁一枚あたりの防衛につく
人数が減ってしまいます。
それぞれ3-4マスほど間隔を開けて建設するのが基本です。


&&Smnc_td_rule_title2 援護射撃.1

/* ___ Smnc_td_rule2 ___ */
ティグリナは宿舎屋上の砲台から
援護射撃で戦闘に参加します。

なお、砲台にこめる弾薬は無限ではなく、
これも予算内に収める必要があります。
壁の建築で余った資金を注ぎ込むと\b良いでしょう。


&&Smnc_td_rule_title3  援護射撃.2

/* ___ Smnc_td_rule3 ___ */
ティグリナは4種類の弾薬から
状況に応じて最適なものを選んで発射します。

弾薬にはノエル及び味方を
巻き込む恐れがあるものも含まれるため、
ノエルが壁外で活動しすぎると
ティグリナが弾を発射し辛くなります。



&&Smnc_td_rule_title4 人員の配置
/* ___ Smnc_td_rule4 ___ */
「人員の配置」では、共に防衛作戦に参加する
味方を場に配置することができます。(最大&1人)

人員を配置する場所によって、自動的に
歩兵、救護兵、砲兵のいずれかの
役割に割り振られます。

&&Smnc_td_rule_title5 歩兵.1
/* ___ Smnc_td_rule5 ___ */
防壁の近く、または物見<rb c="やぐら">櫓</rb>の上に配置
した人員は歩兵となります。

歩兵は防壁を守るため、ホワイトアローまたは
エナジーボールで魔族を攻撃して撃退します。
（櫓上の歩兵はエナジーボールを優先します）


&&Smnc_td_rule_title6 歩兵.2
/* ___ Smnc_td_rule6 ___ */

防壁が破壊されると、歩兵は自動的に戦線を下げ、
後ろの壁から攻撃するようになります。

魔力が不足すると戦えなくなるため、
魔力塔を一本、壁の内側に建てておくと
防衛が安定するでしょう。

&&Smnc_td_rule_title7 砲兵
/* ___ Smnc_td_rule7 ___ */
宿舎の屋上、ティグリナの近くに人員を
配置した場合、その人員は砲兵となります。

砲兵は直接場に現れることはありませんが、
配備すればするほどティグリナの大砲の
発射速度が上昇します。
（人数が多すぎると上昇率が緩やかになります）

&&Smnc_td_rule_title8 救護兵
/* ___ Smnc_td_rule8 ___ */
救護テントの近くに配置した人員は救護兵となり、
アイコンに紫のマークが付与されます。
救護兵は倒れてしまった味方の元に駆け付け、
救護テントまで運んでくれます。

担架で運びやすくするため、2人1組で
人員を配置するのが基本となります。

&&Smnc_td_rule_title9 救護テント
/* ___ Smnc_td_rule9 ___ */
救護テント内に運ばれた倒れた味方は、
しばらくすると快復して戦闘に復帰します。

救護テントを建設するとプリムラが場に登場します。
プリムラがテントで治療活動を行ってくれている
間は、味方一人の快復速度がアップします。

&&Smnc_td_rule_title10 救護テント
/* ___ Smnc_td_rule10 ___ */
ノエルが倒れてしまった場合も、
防壁内であれば救護兵によって救助されます。
最後まで諦めず、街の防衛のため
全力を尽くしましょう。

&&Smnc_td_rule_title11 危険物持ち込み
/* ___ Smnc_td_rule11 ___ */
防衛作戦において、グレネード類の使用は
事故防止のため禁止されています。

/* ___ Smnc_td_rule11_2 ___ */
この回想においては、アイテムをいくら使っても
戦闘終了後に全てリセットされます。
爆弾の使用も含め、思う存分暴れ尽くして
完膚無きまでに魔族を撃退しましょう。
